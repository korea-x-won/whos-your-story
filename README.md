# whos-your-story
Public repository for whos-your-story


## Languages and character versions

- Japanese: `/`; Korean: `/ko/`; English: `/en/`.
- Choose male or female result cards on the title screen. The title screen, quiz and type overview retain the original character illustrations; only the final result artwork switches. The decision tree is unchanged.
- The adopted 1.0–4.5 cards are in `assets/result-cards/{male,female}/`.
- Korean and English results display translated text alongside artwork. Original downloadable cards retain Japanese lettering.
- Shared result pages preserve language and character version in their paths and include X image-preview metadata.
